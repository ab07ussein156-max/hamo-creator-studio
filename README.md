# HAMO Creator Studio

موقع عربي RTL لإدارة سلسلة «أسرار ورا الشاشة».

## تشغيله على جهازك
افتح ملف `index.html` في متصفح حديث.

## نشره مجانًا باستخدام GitHub Pages
1. أنشئ حسابًا مجانيًا على https://github.com/
2. أنشئ مستودعًا جديدًا (Repository) باسم `hamo-creator-studio`.
3. ارفع ملف `index.html` إلى المستودع.
4. افتح Settings ثم Pages.
5. من Build and deployment اختر Deploy from a branch.
6. اختر `main` ومجلد `/ (root)` ثم Save.
7. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## حفظ البيانات
البيانات محفوظة محليًا داخل المتصفح باستخدام localStorage. من صفحة الإعدادات نزّل نسخة JSON احتياطية بانتظام. استعادة النسخة متاحة من نفس الصفحة.

## تنبيه
هذه النسخة لا تحتوي على تسجيل دخول أو قاعدة بيانات سحابية. أي شخص يفتح الرابط سيحصل على نسخة مستقلة من بياناته في متصفحه، ولن يرى بياناتك المحلية. إشعارات المتصفح تعمل فقط عندما يكون الموقع مفتوحًا والمتصفح يسمح بها.
